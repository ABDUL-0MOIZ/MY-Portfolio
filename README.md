## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/ABDUL-0MOIZ/MY-Portfolio.git
```

Go to the project directory:

```bash
cd MY-Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run locally using Vite.

## 📧 EmailJS Configuration

The contact form uses EmailJS.

Create a `.env` file in the project root:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
VITE_EMAILJS_TEMPLATE_OWNER=your_owner_template_id
VITE_EMAILJS_TEMPLATE_REPLY=your_reply_template_id
```

After adding environment variables, restart the development server.

> Do not commit your `.env` file to GitHub.

## 🏗️ Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
